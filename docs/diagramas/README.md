DIAGRAMAS EM DRAW.IO
====================

Diagramas-Contas-Bancarias.drawio  -> os 14 diagramas num só ficheiro, um por separador (página)
Diagramas-Contas-Bancarias.pdf sao todos os diagramas em um documento pdf

Como abrir
  - No browser: https://app.diagrams.net  ->  "Open Existing Diagram" (ou arrastar o ficheiro para a página)
  - Aplicação para Mac: https://github.com/jgraph/drawio-desktop/releases (ou: brew install --cask drawio)
  - No VS Code: extensão "Draw.io Integration" (hediet.vscode-drawio); abre os .drawio directamente

Tudo é editável: caixas, classes (cada atributo é uma linha), tabelas, linhas de vida,
fragmentos alt/loop, setas e notas. Os diagramas de sequência usam as formas UML nativas
do draw.io (Lifeline e Frame).
